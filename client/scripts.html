Oracle Scripts · new

Any data. Not just prices.

An Oracle Script turns any public JSON API into a BEAM oracle feed: weather, sports, index values, on-chain stats, anything a URL returns as a number. Every validator fetches the sources on its own, signs what it saw, and the stake-weighted median goes live as an OS: feed in the stream, the API, tunnels and BeamReceiver on Robinhood Chain.
