BEAM VRF · new

Randomness. With receipts.

Ask for a random number with any seed. The next round's hash fixes the input, every validator signs it with its own key, and the random value is the hash of those signatures. Nobody, BEAM included, knows the value before the round closes, and anyone can recompute it. BeamVRF.sol checks the same signatures on Robinhood Chain.
