For developers: the raw stream
Every finalized round is pushed as a server-sent event, with the price, timestamp, number of reporting validators and 24h change per feed.


const s = new EventSource('https://beamprotocol.org/api/stream?feeds=CS:BTC-USD,EQ:TSLA-USD');
s.addEventListener('round', (e) => {
  const { round, signers, prices } = JSON.parse(e.data);
  console.log(round, prices['EQ:TSLA-USD'].price);
});
